File conventions reference

Every special file, folder pattern, segment export and top-level file in a Next.js 16.3 App Router project, in one table per kind.

NNext.jsCurrentNext.js 16.3+Targets Next.js 16.3

Lookup, not reading. For how these files compose into a route, read File conventions. Labels: Current (stable, no flag), Opt-in (stable, needs a flag), Experimental (needs an experimental.* flag), Deprecated.

Route files#

Special files inside app/. Each applies to the segment (folder) it sits in.

FileExtensionsPurposeLabelVersion notes
layout.js .jsx .tsxShared UI that wraps a segment and its children and persists across navigations. The root app/layout must render <html> and <body>.Currentparams is a Promise (since 15). Type with LayoutProps<'/route'>.
page.js .jsx .tsxMakes a segment publicly routable and renders its UI.Currentparams and searchParams are Promises. Synchronous access was removed in 16.0.
loading.js .jsx .tsxA <Suspense> fallback for the segment.Current
error.js .jsx .tsxError boundary for the segment. Must be a Client Component.Currentretry prop stable in 16.3.0 (renamed from unstable_retry, 16.2).
global-error.js .jsx .tsxError UI for the root layout. Renders its own <html> and <body>.CurrentSame retry prop.
not-found.js .jsx .tsxUI for notFound() and, at the root, unmatched URLs.Current
global-not-found.js .jsx .tsxA 404 for unmatched URLs that bypasses layouts. For apps with several root layouts or a dynamic root segment.ExperimentalNeeds experimental.globalNotFound.
forbidden.js .jsx .tsxUI for forbidden() (403).ExperimentalNeeds experimental.authInterrupts.
unauthorized.js .jsx .tsxUI for unauthorized() (401).ExperimentalNeeds experimental.authInterrupts.
template.js .jsx .tsxLike a layout, but remounts on every navigation.Current
default.js .jsx .tsxFallback for a parallel route slot when the URL does not match it.CurrentRequired for every slot since 16.0. Builds fail without it.
route.js .tsRoute Handler: HTTP endpoints using Web Request / Response.Currentcontext.params is a Promise. GET not cached by default since 15. Type with RouteContext<'/route'>.

Folder conventions#

PatternExampleMeaning
folderapp/blog/page.tsxA URL segment: /blog.
[segment]app/blog/[slug]/page.tsxDynamic segment: /blog/hello.
[...segment]app/help/[...topic]/page.tsxCatch-all: /help/a/b.
[[...segment]]app/wiki/[[...path]]/page.tsxOptional catch-all: also matches /wiki.
(group)app/(marketing)/page.tsxRoute group: organizes files, omitted from the URL. Can hold its own root layout.
_folderapp/blog/_components/post-card.tsxPrivate folder: never routable.
@slotapp/dashboard/@analytics/page.tsxParallel route slot, passed to the parent layout as a prop. Needs default.
(.)folderapp/lookbook/@modal/(.)looks/[lookId]/page.tsxIntercept a sibling route.
(..)folderIntercept one level up.
(..)(..)folderIntercept two levels up.
(...)folderIntercept from the app root.

A dynamic segment above the root layout (for example app/[lang]/layout.tsx) is a root param. Its name becomes an async getter in next/root-params (16.3). The folder name must be a valid JavaScript identifier, so [post-slug] fails.

Common mistakes#

  • A parallel route slot without default.tsx. Builds fail since 16.0.
  • Naming the request interceptor middleware.ts in new code. It is deprecated; write proxy.ts.
  • Putting proxy.ts inside app/. It belongs at the project root or in src/, next to app/.
  • Exporting dynamic or revalidate with Cache Components on. Both are build errors under cacheComponents.
  • Kebab-case root param folders such as app/[site-locale]. next/root-params needs a valid identifier.
  • Using forbidden.tsx without experimental.authInterrupts. The file is ignored until the flag is on.
